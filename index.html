WALL-E AI 固件刷机页

自研固件（支持 OV5640 自动对焦）· 基于 xiaozhi-esp32
刷之前先做一件事：把设备后台（xiaozhi.me 控制台）里的 「OTA 升级」开关关掉。
只要它还开着，刷完一联网就会被自动顶回原厂 2.4.0，白刷一次。
刷机步骤
  1. 用 数据线（不是充电线）把机器连到电脑。
  2. 用 Chrome 或 Edge 打开本页（手机浏览器不行，必须是电脑）。
  3. 点下面的「安装」，在弹出的列表里选设备端口（一般是 COM 开头的那个）。
  4. 等进度条走完，机器会自动重启。
正在读取固件信息…
设备没出现在端口列表里？

按住 BOOT 不放 → 点一下 RESET → 松开 BOOT，就能进入刷机模式，再点一次「安装」。

刷完帮我回答 5 个问题

【1】屏幕：A 有画面 / B 亮但全黑 / C 完全不亮
【2】说话有反应吗：A 能正常对话 / B 有反应但听不清 / C 完全没反应
【3】说"打开摄像头看看这是什么"：A 能说出画面内容 / B 报错打不开 / C 没反应
【4】说"往前走"：A 动了 / B 抖一下或重启 / C 完全不动
【5】方便的话抓一份开机串口日志（115200）截图发我 —— 这条最能定位问题。
